A step-by-step tutorial and reference SwiftUI app built on Liferay DXP 2026.Q1's headless REST APIs. Users sign in with OAuth 2.0 and PKCE, then manage their profile, addresses and a custom Liferay Object, with no third-party dependencies. Partly tested.

SharePoint Online to Liferay DXP migration

A 14-chapter hands-on tutorial, with working tooling, for migrating a live SharePoint Online site, or SharePoint Server on premises, to Liferay DXP 2026.Q3 and its new CMS. MCP servers let an AI agent help inventory the source, plan the mapping and check the result, and a mock SharePoint lets you try it without a tenant.

A step-by-step guide to running Liferay DXP on Amazon EC2, as a single instance or in high availability, with Docker or the Tomcat bundle. Terraform builds the infrastructure and GitHub Actions deploys your code. Draft, partly tested on AWS.
