获取最新信息

获取最新的教程和示例

所有内容均在 GitHub 上发布。您可以通过以下方式在有新内容时收到通知。

  1. 关注 @Liferay-Community-APAC

    新的代码库和动态会显示在您的 GitHub 动态中。

  2. 关注版本发布

    在您感兴趣的代码库中选择 Watch → Custom → Releases，即可在更新时收到通知。

  3. 添加星标

    为有用的代码库加上星标（Star），方便日后查找。
