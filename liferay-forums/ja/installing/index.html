インストール

これらのページでは、空の Liferay から動作するフォーラムサイトまで、Liferay Forums 1.0.0 のインストール手順を説明します。初回は 1 時間ほどを見込んでください。そのほとんどは Liferay の起動待ちの時間です。

始める前に

次のものがそろっていることを確認してください。

  • Liferay DXP 2026.Q1 LTS。Tomcat バンドルからインストールしたサーバー、Docker、Liferay PaaS、または Liferay SaaS 上で動作し、下記の Liferay の修正、またはその回避策が適用されていること。
  • Liferay がサポートするデータベース（PostgreSQL など）。フォーラムは Hypersonic では動作しません。Hypersonic は、データベースが設定されていない場合に Liferay が使用するデモ用のデータベースです。
  • Java 17 以降。Liferay Self-Hosted (Tomcat)でフォーラムのマイクロサービスを実行するマシンと、複数のフォーラムサイト用の site initializer をビルドする場合に必要です。

必要な Liferay の修正

必要な修正を含む、お使いの 2026.Q1 リリース用の hotfix を Liferay サポートに依頼し、フォーラムより先にインストールしてください。Liferay SaaS では、Liferay は hotfix を 1 つの環境ではなくクラスター全体にインストールします。そのため、お使いの環境のリリースに含まれていない修正については回避策を使用してください。Liferay SaaS の場合を参照してください。

修正 適用しない場合 必要か
LPD-90465（2026.Q1.4 ではバックポートの LPD-112124） 利用禁止（ban）が機能せず、モデレーターに Lock Topic が表示されません。 はい
LPD-85594 既存のサイトに site initializer の zip を再度デプロイするたびに、サイトのアドレスがリセットされ、フォーラムのリンクが「見つかりません」ページを表示します。Liferay PaaS と SaaS は対象外ですが、これらではインストール手順で site initializer を再実行しないようにしています。 はい（この修正を含む 2026.Q1.12 より前）
LPD-102310 トピックの更新時に、Liferay が Invalid asset category エラーをログに出力します。それ以外の影響はありません。 いいえ（推奨）

Liferay Forums 1.0.0 は 2026.Q1.1 と 2026.Q1.4 でテストされています。

インストールするもの

各リリースには、次のファイルが含まれています。

ファイル 内容
liferay-forums-batch.zip フォーラムのデータ（トピック、返信、投票、報告、フォロー）と、通知テンプレートおよび検索設定です。
liferay-forums-etc-spring-boot.zip フォーラムのマイクロサービスです。Liferay の横で動作する小さなプログラムで、すべての投稿について利用禁止とロックされたトピックを確認し、通知を送信します。Liferay にはこの zip が必要で、マイクロサービス自体は独立したプロセスまたはコンテナーとして実行されます。
liferay-forums-site-initializer.zip フォーラムサイト本体（ページ、ロール、権限）です。これをデプロイすると、フォーラムサイトが 1 つ作成されます。
generate-site-initializer-zips.sh Liferay Self-Hosted で、複数のフォーラムサイトを運用するために、site initializer の zip をサイトごとに 1 つずつ作成します。
liferay-forums-<version>-source.zip 3 つの zip のソースで、Liferay Workspace の形式です。Liferay PaaS の場合、追加のフォーラムサイトごとに site initializer をビルドする場合、またはご自身の Liferay Workspace にフォーラムを追加する場合に必要です。
SHA256SUMS 上記ファイルのチェックサムです。

Liferay の実行環境を選ぶ

Liferay Self-Hosted (Tomcat)Tomcat バンドルからインストールした Liferay。マイクロサービスは同じマシンまたは別のマシンで実行します。 Liferay Self-Hosted (Docker)コンテナーで動作する Liferay と PostgreSQL。マイクロサービスは Liferay のコンテナーの横のコンテナーで実行します。 Liferay PaaS の場合フォーラムのプロジェクトを PaaS プロジェクトのリポジトリに追加し、プロジェクトの他の部分と一緒にデプロイします。 Liferay SaaS の場合フォーラムの zip を Liferay Cloud のコマンドラインツールで 1 つずつデプロイします。

Liferay Self-Hosted では、その後にフォーラムサイトの作成、続いてインストールの確認を行います。Liferay PaaS と Liferay SaaS では、フォーラムサイトはインストール中に作成されます。すべてのインストール方法で、さらにフォーラムサイトを追加する方法についてはフォーラムサイトの作成を参照してください。

ご自身の Liferay のコードを Liferay Workspace でビルドしている場合は、Liferay Workspace を使った開発を参照して、フォーラムのプロジェクトを追加してください。

順序が重要な理由

フォーラムは決まった順序でインストールします。batch、マイクロサービス、サイトの順です。各手順には、その前の手順が必要です。

  • batch が最初です。 マイクロサービスの zip がデプロイされると、Liferay はマイクロサービスにフォーラムのデータへのアクセス権を与えますが、その時点で存在する部分に対してだけです。batch の完了前にデプロイされると、マイクロサービスはアクセス権を得られず、すべての投稿が拒否されます。
  • サイトは最後に、Liferay が完全に起動してから作成します。 Liferay の起動中に作成されたフォーラムサイトには、トピックのページがありません。これは、Liferay の停止中に site initializer の zip をコピーした場合に起こります。そのため、site initializer は必ず実行中の Liferay にデプロイしてください。
