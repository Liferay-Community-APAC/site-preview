Liferay Forums

Modern discussion forums for Liferay DXP

Discussion forums for Liferay DXP. Members ask questions, share answers and follow topics, while moderators keep the community healthy.

Version 1.0.0 · Works with Liferay DXP 2026.Q1 LTS

Read the guide → Download

Powered by Liferay AI Hub. Add an AI assistant that tells members where to find the discussions they're looking for, searching only what each member can see, and an AI summary at the top of busy discussions.
Forums Assistant → · AI Discussion Summaries → · About Liferay AI Hub

Features

  • Discussions and questions. Post a topic as an open discussion, or as a question members can mark as solved.
  • Mentions and subscriptions. Mention members with @, and get web and email notifications for the topics you follow.
  • Moderation. Members report content; moderators validate reports, lock or delete topics, and ban authors per site.
  • Search. Find topics with facets for category, tag, author and date.
  • Categories. Organize topics into categories, with one level of subcategories.
  • Voting. Upvote or downvote topics and replies.
  • Several sites. Run separate forums, each with its own categories, topics and bans.
  • 13 languages. Labels ship in 13 languages, including Japanese and Chinese.

Liferay Migration Studio

Coming soon: move content from any system with an API into Liferay DXP

Migrate content into Liferay DXP 2026.Q1 and later from older Liferay versions and other systems with an API. Map in a web UI, dry-run every request, load at scale, then validate the result against the source.

Works with Liferay DXP 2026.Q1 or later

Read the guide →

Features

  • Map in a web UI. Connect a source and Liferay DXP, map entities and fields, and preview the exact requests for real records before anything is written.
  • Run order worked out. The order comes from the mappings: vocabularies before categories, parents before children, authors before their posts.
  • Dry run and re-runnable loads. See every request first. Loads run in parallel batches, can stop and resume, and running them again updates records instead of duplicating them.
  • Validation. Record counts, a field-by-field comparison of migrated records read back from Liferay, and the records whose related records weren't migrated.
  • Ready-made migrations. Liferay Web Content from 2024.Q1 to the new CMS in 2026.Q3, tested on real Liferay. SharePoint discussion boards to Liferay Forums are next.
  • Optional AI. Mapping suggestions, explanations of validation problems, and a chat that can dry-run but only proposes loads. Use a hosted model or one you run yourself.
