グローバルコミュニティ

世界の Liferay コミュニティに参加する

世界中のユーザー、お客様、パートナー、Liferay 社員が知見を共有する、Liferay が運営する 2 つの場です。

Liferay Discuss

discuss.liferay.com

Liferay の公式コミュニティフォーラムです。Free Tier のユーザー、お客様、パートナー、Liferay 社員など、Liferay を使うすべての方、関心のあるすべての方が参加できます。

  • Development、Capabilities、General などのカテゴリーで質問・回答できます。
  • Product Ideas への投稿や投票、ベータ機能やドキュメントへのフィードバックで製品づくりに参加できます。
  • お知らせや DEVCON の最新情報をチェックできます。

Marketplace アプリ、チュートリアル、ツールについてのご質問は Development カテゴリーへ。詳しくはサポートをご覧ください。

最新情報を受け取る

最新のチュートリアルやサンプルをお届けします

すべてのコンテンツは GitHub で公開しています。新しいコンテンツの通知を受け取るには、次の方法をご利用ください。

  1. @Liferay-Community-APAC をフォロー

    新しいリポジトリや更新情報が GitHub のフィードに表示されます。

  2. リリースを Watch

    関心のあるリポジトリで Watch → Custom → Releases を選択すると、更新時に通知が届きます。

  3. Star を付ける

    役に立ったリポジトリに Star を付けておくと、あとから簡単に見つけられます。

コミュニティのサポート

Marketplace アプリ、ソリューションレシピ、チュートリアル、ツールに関するご質問は、Liferay Discuss の Development カテゴリーに投稿してください。コミュニティのメンバーがベストエフォートで回答します。

Liferay Discuss へのサインインが必要です。投稿は公開されるため、機密情報は含めないでください。投稿は英語でお願いします。

サブスクリプションのサポート

Liferay DXP のサブスクリプションをお持ちの方は、公式サポートのチケットを作成してください。
