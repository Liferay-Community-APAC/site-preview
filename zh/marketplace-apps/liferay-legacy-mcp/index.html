Liferay Legacy MCP

将 AI 助手连接到没有自带 MCP 服务器的 Liferay DXP 版本

适用于 Liferay DXP 2024.Q1 至 2025.Q4 以及 7.4 更新版本的 MCP 服务器。Claude Code 等 AI 助手可以用自然语言查找、读取和修改 Liferay 中的内容，遵循 Liferay 自身的权限，并且在任何更改之前都会先显示预览供您确认。适用于在测试或开发环境中试用。

版本 1.1.0 · 适用于 Liferay DXP 2024.Q1 to 2025.Q4 and 7.4

阅读指南（英文） →

功能

  • 面向没有 MCP 的版本. 无需修改 Liferay，即可让 2024.Q1 至 2025.Q4 以及 7.4 更新版本支持 AI 访问。2026.Q1 及更高版本已内置此功能。
  • 内容工具. 搜索、读取、创建和更新 Web 内容、文档、博客、分类、标签、导航菜单、知识库文章和翻译，并运行审核工作流。
  • 需要时可用所有 API. 通用工具可以访问 Liferay 的所有 Headless REST API 和 JSON Web 服务，不限于专用工具。
  • 安全写入. 写入默认关闭。开启后，每项更改都会先显示预览，确认后才会执行，所有操作都会记录在审计日志中。
  • 最小权限. 服务器以一个服务用户的身份，通过 OAuth 2 应用运行，其作用域限制了可访问的范围。
  • 页面检查. 以访客或只读用户身份查看页面的标题、链接、缺失的图片说明和错误，并截取屏幕截图。
