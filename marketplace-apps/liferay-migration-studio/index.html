Liferay Migration Studio

Coming soon: move content from any system with an API into Liferay DXP

Migrate content into Liferay DXP 2026.Q1 and later from older Liferay versions and other systems with an API. Map in a web UI, dry-run every request, load at scale, then validate the result against the source.

Works with Liferay DXP 2026.Q1 or later

Read the guide →

Features

  • Map in a web UI. Connect a source and Liferay DXP, map entities and fields, and preview the exact requests for real records before anything is written.
  • Run order worked out. The order comes from the mappings: vocabularies before categories, parents before children, authors before their posts.
  • Dry run and re-runnable loads. See every request first. Loads run in parallel batches, can stop and resume, and running them again updates records instead of duplicating them.
  • Validation. Record counts, a field-by-field comparison of migrated records read back from Liferay, and the records whose related records weren't migrated.
  • Ready-made migrations. Liferay Web Content from DXP 7.3 to the new CMS in 2026.Q3, tested on real Liferay. SharePoint discussion boards to Liferay Forums are next.
  • Optional AI. Mapping suggestions, explanations of validation problems, and a chat that can dry-run but only proposes loads. Use a hosted model or one you run yourself.
