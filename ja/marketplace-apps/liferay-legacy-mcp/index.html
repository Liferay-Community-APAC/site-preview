Liferay Legacy MCP

MCP サーバーを持たない Liferay DXP のリリースに AI アシスタントを接続

Liferay DXP 2024.Q1〜2025.Q4 と 7.4 のアップデートリリース向けの MCP サーバーです。Claude Code などの AI アシスタントが、Liferay の権限のもとで、自然な言葉で Liferay のコンテンツを検索、参照、変更できます。変更は必ずプレビューを確認してから実行されます。テスト環境や開発環境での試用向けです。

バージョン 1.1.0 · 対応製品 Liferay DXP 2024.Q1 to 2025.Q4 and 7.4

ガイドを読む（英語） →

機能

  • MCP がないリリース向け. Liferay を変更せずに、2024.Q1〜2025.Q4 と 7.4 のアップデートリリースから AI を利用できるようにします。2026.Q1 以降は標準で備えています。
  • コンテンツツール. Web コンテンツ、ドキュメント、ブログ、カテゴリー、タグ、ナビゲーションメニュー、ナレッジベース記事、翻訳を検索、参照、作成、更新し、レビューのワークフローを実行できます。
  • 必要なときはすべての API. 汎用ツールで、専用ツールの範囲を超えて Liferay のすべての Headless REST API と JSON Web サービスにアクセスできます。
  • 安全な書き込み. 書き込みは既定でオフです。オンにすると、すべての変更がプレビューとして表示され、確認後にのみ実行されます。すべての操作は監査ログに記録されます。
  • 最小権限. サーバーは 1 人のサービスユーザーとして、OAuth 2 アプリケーションを通じて動作します。アクセスできる範囲はそのスコープで制限されます。
  • ページの検査. ゲストまたは閲覧のみのユーザーとして、ページの見出し、リンク、画像の説明の欠落、エラーを確認し、スクリーンショットを撮れます。
