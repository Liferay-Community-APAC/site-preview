Liferay Legacy MCP

Connect AI assistants to Liferay DXP releases with no MCP server of their own

An MCP server for Liferay DXP 2024.Q1 to 2025.Q4 and the 7.4 update releases. AI assistants such as Claude Code can find, read and change your Liferay's content in plain language, with Liferay's own permissions and a preview you confirm before anything changes. For experimental use on a test or development copy.

Version 1.1.0 · Works with Liferay DXP 2024.Q1 to 2025.Q4 and 7.4

Read the guide →

Features

  • For releases with no MCP. Brings AI access to 2024.Q1 to 2025.Q4 and the 7.4 update releases, without changing Liferay. 2026.Q1 and later have it built in.
  • Content tools. Search, read, create and update web content, documents, blogs, categories, tags, navigation menus, knowledge base articles and translations, and run review workflows.
  • Every API, when you need it. Generic tools reach all of Liferay's Headless REST APIs and JSON web services, beyond the dedicated tools.
  • Safe writes. Writes are off by default. When on, every change is shown as a preview and runs only once confirmed, and every attempt is written to an audit log.
  • Least privilege. The server acts as one service user, through an OAuth 2 application whose scopes limit what it can reach.
  • Page inspection. See a page's headings, links, missing image descriptions and errors, and take screenshots, as a guest or a view-only user.
