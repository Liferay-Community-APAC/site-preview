インストールの確認

4 つの簡単な確認で、フォーラムが動作していることがわかります。いずれかが失敗した場合は、以下の対処方法で一般的な原因を解決できます。

  1. 確認 1: マイクロサービス
  2. 確認 2: Forum Banned ロール
  3. 確認 3: 投稿
  4. 確認 4: メールを受信する
  5. 問題がある場合
    1. 投稿が拒否される
    2. トピックのリンクで「見つかりません」ページが表示される
    3. 利用禁止が機能しない、またはモデレーターに Lock Topic が表示されない
    4. メールが届かない
  6. 関連情報

確認 1: マイクロサービス

Liferay のマシンで、次のコマンドを実行すると READY と出力されます。

curl http://localhost:58081/ready

Liferay Self-Hosted (Docker)では、docker exec forums-liferay curl -s http://localhost:58081/ready を実行します。

Liferay PaaS と Liferay SaaS では、Liferay Cloud コンソールで liferayforumsetcspringboot サービスが動作していることを確認します。

確認 2: Forum Banned ロール

管理者として Liferay にサインインした状態で、<liferay-url> をお使いの Liferay のアドレスに置き換えて、次のアドレスを開きます。最初のフォーラムサイトが作成されていれば、「見つかりません」エラーではなく、Forum Banned ロールが表示されます。

<liferay-url>/o/headless-admin-user/v1.0/roles/by-external-reference-code/FORUM_BANNED

確認 3: 投稿

  1. 管理者として、初回のセットアップを完了します。投稿するには、カテゴリーが少なくとも 1 つ存在する必要があります。
  2. メンバーとしてサインインし、フォーラムサイト（たとえば /web/forums）を開いて、トピックを作成します。
  3. そのトピックに返信します。

確認 4: メールを受信する

  1. あるメンバーとして、トピックをフォローします。
  2. 別のメンバーとして、そのトピックに返信します。
  3. 最初のメンバーに、メール通知で設定したアドレスからメールが届くことを確認します。

問題がある場合

投稿が拒否される

メンバーが利用禁止されておらず、トピックもロックされていないのに、Your account has been banned from participating in the forums. またはロックのエラーが表示されます。

  1. マイクロサービスが動作していること、および Liferay からマイクロサービスに接続できることを確認します（確認 1）。Liferay Self-Hosted (Docker)では、Liferay のコンテナーを再起動した後に、マイクロサービスのコンテナーを再起動してください。
  2. 動作しているのに、そのログに Liferay からの 403 エラーが表示される場合は、batch の完了前にその zip がデプロイされたため、Liferay がフォーラムのデータへのアクセス権を与えていません。同じ zip を再度デプロイしても解決しません。新たにデプロイし直してください。
    1. Liferay の osgi/client-extensions フォルダーから liferay-forums-etc-spring-boot.zip を削除します。
    2. Liferay のログにそのバンドルの STOPPED が表示されるまで待ちます。
    3. zip を再びコピーします。
    4. マイクロサービスを再起動します。
  3. Liferay PaaS では、Liferay PaaS へのインストールのとおり、2 回目のビルドをデプロイしてマイクロサービスを再起動します。Liferay SaaS では、マイクロサービスの client extension の削除を Liferay サポートに依頼してから、再度デプロイします。

トピックのリンクで「見つかりません」ページが表示される

Liferay の起動中にサイトが作成されたため、トピックのページがありません。誰かがそのサイトに投稿する前に、Control Panel → Sites でサイトを削除し、フォーラムサイトの作成のとおり、実行中の Liferay にそのサイトの site initializer の zip を再度デプロイします。

利用禁止が機能しない、またはモデレーターに Lock Topic が表示されない

Forum Banned ロールに外部参照コード FORUM_BANNED が設定されていません。これは、Liferay の修正 LPD-90465 がない場合に起こります。管理者としてサインインし、たとえば <liferay-url>/o/api にある Liferay の API エクスプローラーを使って、手動で設定します。

  1. ロールの ID を調べます: GET /o/headless-admin-user/v1.0/roles?search=Forum%20Banned。
  2. コードを設定します: PATCH /o/headless-admin-user/v1.0/roles/<role ID>、本文は {"externalReferenceCode": "FORUM_BANNED"} です。
  3. 確認 2 でロールが表示されるようになったことを確認します。

メールが届かない

メール通知で、テンプレートの From アドレスと Liferay のメール送信者を確認し、Liferay のメールサーバーが設定されていることを確認してください。テンプレートを変更した後は、マイクロサービスを再起動してください。マイクロサービスは起動時にだけテンプレートを読み込みます。
