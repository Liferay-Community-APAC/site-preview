Liferay Migration Studio

Segera hadir: pindahkan konten dari sistem apa pun yang memiliki API ke Liferay DXP

Migrasikan konten ke Liferay DXP 2026.Q1 dan yang lebih baru dari versi Liferay lama dan sistem lain yang memiliki API. Petakan di UI web, uji setiap permintaan dengan dry run, muat dalam skala besar, lalu validasi hasilnya terhadap sumber.

Untuk Liferay DXP 2026.Q1 or later

Baca panduan (bahasa Inggris) →

Fitur

  • Pemetaan di UI web. Hubungkan sumber dan Liferay DXP, petakan entitas dan field, lalu pratinjau permintaan untuk record nyata sebelum apa pun ditulis.
  • Urutan dijalankan otomatis. Urutan ditentukan dari pemetaan: kosakata sebelum kategori, induk sebelum anak, penulis sebelum postingannya.
  • Dry run dan muat ulang yang aman. Lihat setiap permintaan terlebih dahulu. Pemuatan berjalan dalam batch paralel, dapat dihentikan dan dilanjutkan, dan menjalankannya lagi memperbarui record tanpa menduplikasinya.
  • Validasi. Jumlah record, perbandingan per field dari record yang dibaca kembali dari Liferay, dan record yang record terkaitnya tidak dimigrasikan.
  • Migrasi siap pakai. Web Content Liferay dari DXP 7.3 ke CMS baru di 2026.Q3, diuji pada Liferay sungguhan. Papan diskusi SharePoint ke Liferay Forums menyusul.
  • AI opsional. Saran pemetaan, penjelasan masalah validasi, dan chat yang dapat menjalankan dry run tetapi hanya mengusulkan pemuatan. Gunakan model yang di-host atau model yang Anda jalankan sendiri.

Marketplace App ini bukan produk resmi Liferay dan tidak mendapat dukungan resmi Liferay, sama seperti Marketplace App dari Liferay Community di Liferay Marketplace. Aplikasi ini tidak diperbarui untuk setiap rilis kuartalan: sebagian hanya dipelihara untuk rilis kuartalan tertentu, sesuai kebutuhan. Dukungan berbasis upaya terbaik (best effort) mungkin tersedia untuk akun dengan paket Technical Account Manager (TAM), berdasarkan kasus per kasus. Hubungi Success Delivery Manager Anda untuk informasi lebih lanjut. Uji secara menyeluruh di lingkungan non-produksi sebelum mengandalkannya.
