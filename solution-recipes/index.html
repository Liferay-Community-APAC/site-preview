Solution Recipes

Each recipe combines Marketplace Apps, tutorials and Liferay DXP features into one working use case: what you’ll build, the ingredients you need, and the steps to put them together.

Recipes are unofficial guides, like the Marketplace Apps and tutorials they use. Test them in a non-production environment before relying on them.

How a Recipe Is Organized

Every recipe follows the same structure:

  1. What you’ll build: the use case and the end result.
  2. Ingredients: the Marketplace Apps, tutorials and Liferay DXP features it uses, each linking to its guide.
  3. Steps: how to combine them, in order.
  4. Result: how to check that it works, and where to go next.

To suggest or contribute a recipe, open an issue or a pull request in the solution-recipes repository.
