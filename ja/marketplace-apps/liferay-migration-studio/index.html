Liferay Migration Studio

近日公開：API を持つあらゆるシステムから Liferay DXP へコンテンツを移行

旧バージョンの Liferay や API を持つ他のシステムから、Liferay DXP 2026.Q1 以降へコンテンツを移行します。Web UI でマッピングし、すべてのリクエストをドライランで確認してから大量のデータを読み込み、移行元と照らし合わせて結果を検証します。

対応製品 Liferay DXP 2026.Q1 or later

ガイドを読む（英語） →

機能

  • Web UI でマッピング. 移行元と Liferay DXP に接続し、エンティティとフィールドをマッピングして、書き込む前に実際のレコードで送信されるリクエストをプレビューできます。
  • 実行順序を自動で判断. 実行順序はマッピングから決まります。カテゴリーの前にボキャブラリー、子の前に親、投稿の前に作成者を移行します。
  • ドライランと再実行可能な読み込み. まずすべてのリクエストを確認できます。読み込みは並列バッチで実行され、中断して再開でき、再実行してもレコードは重複せず更新されます。
  • 検証. レコード数、Liferay から読み戻した移行済みレコードとのフィールドごとの比較、関連レコードが移行されなかったレコードの一覧を確認できます。
  • すぐに使える移行. Liferay DXP 7.3 以降の Web コンテンツを 2026.Q3 の新しい CMS へ移行（実環境の Liferay で検証済み）。SharePoint のディスカッション掲示板から Liferay Forums への移行も準備中です。
  • オプションの AI. マッピングの提案、検証で見つかった問題の説明、ドライランは実行できても読み込みは提案のみ行うチャットを利用できます。ホスト型のモデルも、自分で運用するモデルも使えます。
