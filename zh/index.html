赞助方

Liferay 客户成功团队如何为您提供支持

Liferay 亚太地区客户成功团队赞助本社区，并在您使用 Liferay 的每个阶段为您提供支持。

  1. 01

    入门与采用

    我们帮助您快速从 Liferay 获得价值：在项目启动时设定清晰的目标，围绕这些目标制定成功计划，并在您的团队采用平台的过程中提供支持。

  2. 02

    技术咨询与健康检查

    我们对照 Liferay 最佳实践，审查您的架构、配置、性能和定制内容，并为您提供清晰、按优先级排序的改进计划。

  3. 03

    升级、迁移与生命周期管理

    我们帮助您跟上 Liferay 的季度发布：规划升级，从旧平台迁移内容，并确保您始终使用受支持且安全的版本。

  4. 04

    赋能与知识分享

    我们以实践指南、示例代码和可复用工具的形式分享 Liferay DXP 的实用经验，让您的团队能够充满信心地进行开发。

  5. 05

    合作伙伴关系与可衡量的价值

    我们是您的长期合作伙伴。通过定期业务回顾跟踪对您重要的成果，并在您需要时为您对接合适的 Liferay 专家。

获取最新的教程和示例

所有内容均在 GitHub 上发布。您可以通过以下方式在有新内容时收到通知。

  1. 关注 @Liferay-Community-APAC

    新的代码库和动态会显示在您的 GitHub 动态中。

  2. 关注版本发布

    在您感兴趣的代码库中选择 Watch → Custom → Releases，即可在更新时收到通知。

  3. 添加星标

    为有用的代码库加上星标（Star），方便日后查找。
